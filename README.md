# Weather App

A simple, beautiful weather application that displays current weather information for any city.

## Features

- 🌤️ Real-time weather data
- 🎨 Beautiful gradient UI
- 📱 Responsive design
- 🔍 Search any city worldwide
- 📊 Detailed weather information (temperature, humidity, wind speed, pressure)

## Setup

1. Get a free API key from [WeatherAPI](https://www.weatherapi.com/)
2. Open `index.html` and replace `YOUR_API_KEY_HERE` with your actual API key
3. Open `index.html` in your browser

## Usage

Simply enter a city name and click Search or press Enter to see the current weather!
